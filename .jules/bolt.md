## 2025-03-09 - `replaceInFile` 불필요한 디스크 I/O 최적화
**학습 내용:** `scripts/lib/utils.js`의 `replaceInFile` 유틸리티 함수가 교체할 내용이 없는(검색 패턴과 일치하지 않는) 경우에도 변경되지 않은 전체 파일 내용을 디스크에 다시 쓰는(write) 동작을 수행하고 있었습니다. 불필요한 디스크 쓰기는 특히 큰 파일이나 여러 파일에 걸쳐 반복될 때 심각한 성능 병목을 초래합니다.
**적용 계획:** 파일 내용을 수정하는 함수를 작성하거나 검토할 때에는, 항상 변경 사항이 실제로 발생했는지 (`newContent !== content`) 먼저 확인하고, 변경된 경우에만 디스크에 기록(I/O)하도록 방어적 코딩(defensive coding) 패턴을 적용해야 합니다.
